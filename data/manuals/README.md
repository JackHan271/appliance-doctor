# 手册 RAG 语料说明

本目录存放冰箱说明书的 RAG 语料，用于本地个人 demo。

## 合规（见 docs/05-数据策略.md）

- 说明书受版权保护：仅本地使用，**不公开分发、不商用、不入代码仓库**。
- `raw/` 目录（下载的 PDF）应加入 `.gitignore`。

## 采集流程

1. 在 `collect_manuals.py` 的 `SOURCES` 列表填入说明书 PDF 直链（优先厂商官网）。
2. 本机运行 `python collect_manuals.py`，文件下载到 `raw/`。
3. 用解析脚本把 PDF 转成文本并切分入库。

## 建议语料清单（按优先级）

- 海尔冰箱说明书（1-2 份代表性型号）
- 美的冰箱说明书
- 西门子冰箱说明书
- 通用家电安全手册（作为"通用安全手册"模块的 RAG 语料）
