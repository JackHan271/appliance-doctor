# 设计规范

版本：v1（2026-09-18）

## 1. 三级安全护栏（本项目核心设计）

| 等级 | 定义 | 软件行为 |
|------|------|----------|
| 🟢 绿 | 可安全自修（清滤网、除霜、复位、清排水口等断电可做、无风险） | 给出详细步骤 |
| 🟡 黄 | 谨慎操作（换门封条、疏通排水、简单拆面板清理等） | 强制断电 + 警示 + 详细步骤 |
| 🔴 红 | 必须联系专业师傅（制冷剂、压缩机、电路板、电机、高压、燃气相关） | **只解释原因，不教危险步骤**，建议联系售后 |

安全审查 Agent 在用户动手前做最后把关：核对是否已断电、是否涉及高压/制冷剂/燃气、是否会导致保修失效。

## 2. 数据 Schema（建议字段，待用户确认）

### 2.1 个人家电名单（appliance）
- brand（品牌）
- model（型号）
- category（品类：冰箱）
- purchase_date（购买日期）
- warranty_end（保修截止）
- note（备注）

### 2.2 维修历史记录（repair_history）
- time（时间）
- appliance_id（关联家电）
- question（问题描述）
- photo（照片）
- diagnosis（诊断结论）
- safety_level（安全等级：绿/黄/红）
- resolved（是否解决）

### 2.3 故障码（fault_code）
- brand（品牌）
- category（品类）
- code（故障码，如 E1）
- meaning（含义，如"排水超时"）
- level（对应安全等级）
- source（来源）

## 3. UI 模块规范

- 四大区域：个人家电名单 / 提问交互区（核心，最大）/ 维修历史记录 / 通用安全手册。
- 主色调：淡蓝色（建议主色 `#E3F2FD` 系，配深蓝 `#1565C0` 强调）。
- 提问交互区承载：文字输入 + 照片上传 + 诊断对话流 + 安全等级标识 + 步骤卡片。
- 安全提示条：诊断结论顶部必须展示绿/黄/红等级色块与对应安全措施。

## 4. 输出规范

- 诊断回答必须含：结论、安全等级、详细步骤（或"联系师傅"建议）、安全措施、引用来源（手册/故障码出处）。
- 范围外/未知型号必须诚实降级（"该型号未收录，建议读铭牌或联系售后"），不得编造。
