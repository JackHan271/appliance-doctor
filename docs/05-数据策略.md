# 数据策略

版本：v1（2026-09-18）

## 1. 三类数据与合规判断

| 数据 | 来源 | 版权/合规 | 使用方式 |
|------|------|-----------|----------|
| 故障码表 | 厂商官网、说明书附录、维修论坛 | 事实性技术参数，无版权问题，**最安全** | 可自由收集整理成 CSV/JSON |
| 说明书/维修手册 | 厂商官网、公开文档 | 受版权保护 | 仅本地 RAG 个人 demo 用，**不公开分发、不商用** |
| 图片 | 自拍 / CC0 / CC BY 授权 / AI 合成 | 自拍与授权图安全；网上盗图有风险 | 优先自拍或合成（铭牌图可脚本生成） |

## 2. 开源原则

代码与数据分离：代码可开源；手册语料与图片不随代码分发，只提供**采集脚本**或**示例数据**。

## 3. 数据量认知

数据量决定「覆盖范围」，不决定「准确率」。本项目的准确率靠架构保证（确定性查表 + RAG 溯源 + 安全审查 + 评估集），而非堆数据量。MVP 聚焦 3-4 品牌高频故障，范围外诚实降级。

## 4. 采集动作约定

需要批量下载图片或抓取网页时，由用户在本机运行采集脚本（脚本可代为编写），不在协作环境内绕过访问限制批量抓取。
