## 3. Milvus 部署说明

- Milvus Lite：`pip install pymilvus` 内嵌运行，零部署，适合开发与小数据。
- Milvus Standalone：官方 docker-compose 一键起，单机演示够用。
- Milvus 分布式：生产级，需要 etcd + MinIO（+ 可选 Pulsar），必要时再上。
