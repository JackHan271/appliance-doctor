# 需求文档（PRD）

版本：v1.1（2026-09-18，核心决策已确认）

## 1. 产品定位

家电故障维修软件，精准为市面常用品牌的**冰箱**提供维修指导。MVP 阶段覆盖 3 个主力品牌（海尔、美的、西门子），验证全流程后再扩展。

## 2. 核心功能

1. **提问**：用户以文字描述或照片的方式提问。
2. **维修讲解**：在严格保证安全的前提下，详细讲解如何维修。
3. **安全保障**：三级安全护栏 + 安全审查 Agent，提供详细安全措施。

## 3. 次要功能

1. **个人家电名单**：用户添加自己的家电（品牌、型号、品类、购买日期、保修截止、备注）。
2. **维修历史记录**：记录每次诊断的时间、家电、问题、照片、结论、安全等级、是否解决。
3. **通用安全手册**：面向所有家电的通用安全须知。

## 4. UI 需求

- 模块化功能分区，共四大区域：
  1. 个人家电名单
  2. 提问交互区（**核心板块，占更大区域**）
  3. 维修历史记录区
  4. 通用安全手册
- 主色调：**淡蓝色**。

## 5. 已确认决策（2026-09-18）

| 决策点 | 结论 |
|--------|------|
| 运行形态 | Web 应用（React + Docker，可加 PWA） |
| 安全边界 | 三级安全护栏（绿/黄/红），安全审查 Agent 把关 |
| 品牌范围 | 海尔、美的、西门子（三品牌） |
| 照片识别 | 故障现象识别 + 型号铭牌识别都要 |
| 技术路线 | 调用 LLM + RAG + 工具调用 + 多 Agent，**不微调** |
